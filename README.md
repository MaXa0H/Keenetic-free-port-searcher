# Keenetic-Netcraze-free-port-searcher
Автоматический подборщик свободного порта в роутерах Zyxel/Keenetic/Netcraze.

Подбирает случайный свободный порт. Полезно, когда в сети много устройств с разными проброшенными наружу портами, и требуется быстро подобрать любой не занятый порт.

Конфиг:
1. Настройки подключения (http/https протокол, IP адрес / домен, порт, логин и пароль)
2. Учёт дефолтных и служебных портов
3. Учёт UPnP портов
4. Возможность добавить свои порты в исключения

Протестировано на Zyxel Keenetic Ultra 1 с версией прошивки Keenetic OS 2.16 delta и Keenetic Ultra KN-1811 с версией Keenetic OS 5.1 Beta 4.
Подходит и для других роутеров с портированной прошивкой Keenetic.
